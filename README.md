

# 🏠 Land Registry Smart Contract

## 📖 Overview

The **Blockchain-Based Land Registry Smart Contract** is designed to revolutionize traditional land registration by providing a **secure, transparent, and tamper-proof** framework for managing property ownership.

This project leverages **blockchain technology** to record and verify land ownership transactions using **smart contracts**, ensuring authenticity, reducing fraud, and eliminating intermediaries in the process.

---

## 🎯 Objective

To build a **decentralized solution** for land management that simplifies:

* Registration of new properties
* Transfer of ownership between users
* Verification of ownership records

and ensures that all transactions are **immutable**, **verifiable**, and **efficiently managed** on the blockchain.

---

## ⚙️ Features

* **Decentralized Ownership Records** – Stored securely on blockchain, preventing manipulation.
* **Smart Contract Automation** – Handles registration and ownership transfer without intermediaries.
* **Transparency & Security** – All records are publicly verifiable and tamper-proof.
* **Fraud Prevention** – Eliminates risks of double ownership and document forgery.
* **Efficiency** – Streamlines registration and verification processes.

---

## 🧩 Tech Stack

* **Blockchain Platform:** Ethereum
* **Smart Contract Language:** Solidity
* **Development Tools:** Remix IDE, Ganache
* **Testing & Deployment:** MetaMask, Truffle (optional)

---

## 🧠 How It Works

1. **Property Registration:**
   Users can register new land records by providing property details and ownership data, which are stored immutably on the blockchain.

2. **Ownership Transfer:**
   Ownership can be securely transferred between verified users through smart contract functions.

3. **Verification:**
   Anyone can verify land ownership and transaction history directly from the blockchain ledger.

## 🧪 Getting Started

### Prerequisites

* Node.js
* MetaMask wallet
* Remix IDE or Ganache

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/Land-Registry-Smart-Contract.git
   ```
2. Open the `.sol` file in [Remix IDE](https://remix.ethereum.org).
3. Compile and deploy the contract on a local blockchain (Ganache) or test network (e.g., Sepolia, Goerli).
4. Interact with contract functions such as `registerProperty()`, `transferOwnership()`, and `verifyOwner()`.

---

## 🧾 Smart Contract Functions

| Function              | Description                                               |
| --------------------- | --------------------------------------------------------- |
| `registerProperty()`  | Registers a new property under the sender’s ownership.    |
| `transferOwnership()` | Transfers property ownership to another verified address. |
| `verifyOwner()`       | Checks and returns the current owner of a property.       |
